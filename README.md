# DoomFireTest
Custom implementation of doom fire

Inspired by [Doom Fire](https://fabiensanglard.net/doom_fire_psx/)
And [ASCII video player](https://github.com/maxcurzi/tplay)

### Commands to create project

- Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
- npm init -y
- npm install --save-dev typescript
- npx tsc --init

### Build

- npm install / npm ci (update without changeing packages)
- npx tsc

### Run compiled script

- node dist/index.js

### Clean, Build & Serve

- npm run clean
- npm run build
- npx serve .

### Build & Run
- npm run dev
